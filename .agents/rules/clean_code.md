# Clean & Concise Code Guideline

Always adhere to minimal, high-efficiency, and essential code principles:
- **No Unnecessary Code**: Do not include unused variables, redundant wrapper functions, dead code, or placeholder bloat.
- **Keep Components Focused**: Maintain concise, modular, and single-purpose React components.
- **Direct & Performant**: Write clean TypeScript/JavaScript that achieves the goal with minimum complexity.
- **Maintainable Architecture**: Ensure code structure is clear, readable, and easy to extend without over-engineering.
