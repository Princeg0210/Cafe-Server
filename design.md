# Design System & UI Specifications

## Integrated Café Management System

---

## 1. Design Philosophy

The interface should feel like a **premium modern café product**, not a generic restaurant template or an AI-generated dashboard.

The visual language should be:

- Refined
- Minimal
- Warm
- Sophisticated
- Functional
- Editorial
- Tactile
- Calm
- Premium without being flashy

Avoid excessive gradients, glowing elements, excessive rounded cards, unnecessary illustrations, oversized icons, decorative blobs, glassmorphism, neon effects, or overly saturated colors.

The interface should communicate the quality of a premium hospitality brand while remaining extremely easy to operate during busy café hours.

### Core Principle

**Less decoration, better hierarchy.**

Every visual element must have a functional purpose.

---

# 2. Visual Direction

The design should combine:

**Modern editorial design + premium hospitality + contemporary SaaS usability.**

Instead of making every section look like a card, use a combination of:

- Strong typography
- Generous whitespace
- Subtle borders
- Fine dividers
- Structured grids
- Small-radius containers
- Carefully selected imagery
- Subtle shadows
- Clear spacing
- Restrained accent colors

The UI should feel closer to a professionally designed premium product than a template-based dashboard.

---

# 3. Color System

Use a restrained color palette.

### Primary

**Espresso / Charcoal**

Used for:

- Primary navigation
- Headers
- Important surfaces
- POS/KDS dark interfaces

Approximate direction:

`#171513`

### Background

**Warm Off-White / Cream**

Used for the primary customer and administration interfaces.

Approximate direction:

`#F7F4EE`

### Surface

**Soft Warm White**

Used for cards, panels and elevated content.

Approximate direction:

`#FCFBF8`

### Primary Accent

**Muted Amber / Brass**

Use sparingly for:

- Primary actions
- Active states
- Important highlights
- Selected navigation
- Key metrics

Avoid bright yellow or metallic gradients.

Approximate direction:

`#B58A4A`

### Secondary Text

Warm neutral gray:

`#716D66`

### Primary Text

Deep charcoal:

`#1D1B18`

### Borders

Extremely subtle warm gray:

`#E7E2D9`

### Status Colors

Use restrained semantic colors rather than decorative colors:

- Success → muted green
- Warning → muted amber
- Error → muted red
- Information → muted blue

Status colors should primarily communicate meaning and should not dominate the interface.

---

# 4. Typography

Typography should create a premium editorial feeling while maintaining excellent readability.

Use a modern sans-serif as the primary UI font.

Recommended:

**Inter / Geist / SF Pro**

Use consistent typography hierarchy:

### Display

Large section titles.

### Heading

Page and module titles.

### Body

Normal interface content.

### Caption

Metadata and supporting information.

### Numeric / Data

Use tabular or highly legible numeric typography for:

- Prices
- Sales
- Order numbers
- Timers
- Inventory quantities

Avoid excessive font weights.

Use typography and spacing rather than large decorative elements to establish hierarchy.
